# Build-your-own-X

Curated index of step-by-step guides for re-creating well-known technologies from scratch (databases, git, OS, web servers, search engines, shells, bots, and more).

- **Source:** https://github.com/codecrafters-io/build-your-own-x
- **License:** none declared upstream (the repo is a curated link list; this pack is a read-only reference)
- **Contents:** `SKILL.md` (adapted decision rule + workflow for this project), `references/index.md` (the full upstream tutorial index)

Use the adapted `SKILL.md` when the owner wants a capability built in-house instead of paying for a hosted service or adding a vendor dependency.
