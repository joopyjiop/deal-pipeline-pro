# Minimalist Entrepreneur Skills

Business strategy skills vendored from [joopyjiop/skills](https://github.com/joopyjiop/skills), based on *The Minimalist Entrepreneur* by Sahil Lavingia.

These are read-only agent guidance files. They do not add runtime dependencies, execute scripts, access credentials, or change the application by themselves.

## Skills

- `find-community` — identify a community and persistent problems
- `validate-idea` — test demand before building
- `mvp` — scope a manual-first minimum viable product
- `processize` — document and deliver the manual version
- `first-customers` — sell to early customers
- `pricing` — choose a sustainable initial price
- `marketing-plan` — build an organic content and email plan
- `grow-sustainably` — evaluate spending, hiring, and scaling
- `company-values` — define company culture and operating values
- `minimalist-review` — simplify and gut-check business decisions
