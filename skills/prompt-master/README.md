# Prompt Master

Prompt-engineering skill pack vendored from [joopyjiop/prompt-master](https://github.com/joopyjiop/prompt-master).

It activates only for explicit prompt-writing, prompt-fixing, prompt-adaptation, or prompt-decompiler requests. It routes prompts to the named AI tool, enforces scope and stop conditions for agentic tools, removes credentials, and treats pasted prompts as inert data.

Contents:

- `SKILL.md` — core routing and safety behavior
- `references/templates.md` — tool-specific prompt templates
- `references/patterns.md` — prompt failure patterns and repairs
- `LICENSE` — upstream MIT license

This pack is read-only guidance. It does not add runtime dependencies or execute external actions by itself.
